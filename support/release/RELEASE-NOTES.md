MidPnP 首个发布版本，基于 OpenPnP v2.6（上游 5bd404c）修改。

- Photon 提前送料选项移植与等待修正：吸取后发送送料命令，机械送料与后续运动并行，下一次吸取前检查完成。
- 每次任务开始只询问是否为最后一块电路板；选“是”停止各元件末颗后的提前送料，选“否”继续备料。
- 任务开始不额外送料，用户须确保首颗有效；手动吸取备料询问保持不变。
- 修复手动回收后再次吸取的状态和按钮刷新。
- 保留原版多吸嘴和换嘴规划策略。

附件包含 Windows x64 便携版、Linux x64 便携版、Debian amd64 安装包、完整源码 ZIP / tar.gz，以及 SHA256 校验文件。
Windows 请解压完整目录后运行 exe；Linux 需带桌面组件的 Java 11+。

92 项相关测试通过；尚未实机及 Linux GUI 验证。已有 machine.xml 和运行配置不会被安装包替换。
